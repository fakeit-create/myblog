## 按科目

<a id="subject-ds"></a>
### 数据结构

选择题通常为第 1—11 题，综合题通常为第 41—42 题。进入各年份页面后可按题号定位。

<a id="subject-co"></a>
### 计算机组成原理

选择题通常为第 12—22 题，综合题通常为第 43—44 题。

<a id="subject-os"></a>
### 操作系统

选择题通常为第 23—32 题，综合题通常为第 45—46 题。

<a id="subject-cn"></a>
### 计算机网络

选择题通常为第 33—40 题，综合题通常为第 47 题。

## 使用方法

1. 从四科笔记底部的“历年真题跳转”进入本索引。
2. 选择年份和题号定位到题目锚点。
3. 在年份页面打开原卷 PDF 核对完整题干，并用解析 PDF 核对答案。
4. PDF 链接使用 `/files/408/`，对应文件应放在博客的 `source/files/408/`。
